# 新知识库启动信息清单

启动一个全新知识库蒸馏任务前，知识库负责人应提供或确认本清单。信息不完整时可以先做只读盘点，但不能直接进入正式发布。

## 一、知识库基本信息

| 信息 | 是否必填 | 填写说明 |
|---|---|---|
| 源知识库名称 | 是 | 钉钉中显示的空间名称 |
| 源知识库空间 ID | 是 | 用于 DWS 精确读取 |
| 源知识库链接 | 是 | 可人工打开的空间链接 |
| 所属部门 | 是 | 业务归属部门名称 |
| 稳定 ID 部门前缀 | 是 | 简短、唯一、确定后尽量不修改 |
| 盘点快照时间 | 是 | 本轮全量范围对应的时间点 |
| 目标知识库 | 发布时必填 | 仅本地任务可暂不填写 |

## 二、处理范围

- 要处理的空间、目录或节点范围；
- 明确排除的目录、文档和附件类型；
- 是否包含历史版本、回收站、快捷方式和外部链接；
- 已确认独立图片、音频、视频、压缩包和纯扫描PDF不进入Raw；
- 是否允许读取受限目录；
- 本轮是全量蒸馏还是增量蒸馏。

## 三、本地工作信息

| 信息 | 是否必填 | 填写说明 |
|---|---|---|
| 本地工作目录 | 是 | 使用绝对路径，仅保存本轮结果 |
| 是否仅本地处理 | 是 | `true` 时禁止线上写入和发布 |
| 原始文件保存策略 | 是 | 是否保存附件原件和在线文档 Raw Mirror |
| 缓存保留周期 | 建议 | 明确缓存、临时文件和日志的清理规则 |
| 交付目录 | 是 | 业务负责人最终审核的位置 |

## 四、业务规则

- 部门业务分类表及各分类定义；
- 原目录到业务目录的分类原则；
- 本次AI任务发起人；该发起人同时作为执行审核人；
- 文档状态、版本和有效期判断规则；
- 部门常见业务编号及格式；
- 需要特别识别的制度、流程、模板、案例等文档类型；
- 部门专有词、缩写和同义词对照；
- 关系判断的部门补充规则。

## 五、人员与审核

| 角色 | 需要提供的信息 |
|---|---|
| 知识库负责人 | 姓名或角色、联系方式、最终签署职责 |
| 本次任务发起人 | 使用AI执行规范，并作为本次执行审核人和L2抽样检查人 |
| 业务负责人 | 仅提供可确认L3高风险关系的业务范围 |
| 权限负责人 | 可确认的敏感目录和跨权限关系范围 |
| 发布执行人 | 获批后执行发布和回读的人员或角色 |

## 六、敏感与权限范围

- 禁止处理的目录和文件；
- 只允许记录元数据、不允许保存正文的范围；
- 个人信息、客户信息、财务、人事、法务等敏感类别；
- 不同人群的访问权限；
- 关系只有在用户同时拥有两端权限时才展示；是否存在部门要求的更严格限制；
- 本地结果的可访问人员和保存期限。

## 七、技术环境

- DWS 已安装并能够只读访问源知识库；
- Codex 可以访问本地工作目录；
- DOCX、可检索PDF、含文字PPTX、XLSX/钉钉表格、CSV、MD和TXT的解析环境可用；
- 网络和下载权限满足源附件读取要求；
- 存储空间足以保存原始文件和双目录页面；
- 发布前已单独确认线上写权限和目标空间。

## 八、交付期望

至少确认以下交付物是否需要：

- 原目录镜像；
- 业务知识目录；
- 17 字段元数据；
- Raw Mirror 和 Original Content；
- 页首统一AI检索元数据、AI问答入口和轻量知识库地图；
- 两套视图的各层目录索引；
- 关系台账、L2 抽样清单和 L3 确认清单；
- 下载或解析失败清单；
- 本地验收报告；
- 发布清单和回读报告；
- 面向 Codex 问答的 AGENTS.md。
- 逐文档处理结果矩阵、待办动作清单和负责人下一步。

## 九、启动门槛

满足以下条件后可开始全量蒸馏：

- [ ] 源知识库空间 ID 和范围明确。
- [ ] Raw收集材料已经按照最新版入库标准形成准入和排除结果。
- [ ] 本地工作目录和交付目录明确。
- [ ] 本地处理或线上发布边界明确。
- [ ] 业务分类至少有初版；Owner固定取原文创建者。
- [ ] L3 业务确认人和权限负责人明确。
- [ ] 敏感内容范围明确。
- [ ] 源库只读访问测试成功。

满足以下条件后才可进入线上发布：

- [ ] 目标知识库和目标目录明确。
- [ ] 业务负责人已完成 L3 确认。
- [ ] 权限负责人已完成权限检查。
- [ ] 本地验收全部通过。
- [ ] 任务启动时已在 `task-config.yaml` 启用 `publishing`，填写最终写回文件夹链接、发布根目录名和两套视图范围；该配置即为本次任务写入授权。
- [ ] 已确认只允许新建和更新本程序创建的节点，不允许删除、移动、改权限或覆盖既有节点。
- [ ] 已确认烟雾测试页面数、DWS并发上限（默认30）和失败重试策略。
