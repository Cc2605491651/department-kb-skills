# 来源获取、下载与解析执行规范

本文件属于蒸馏执行规范，只处理已经通过《Raw原始材料收集与入库标准》的来源。它不是Raw收集入库标准。

## 1. 盘点字段

每个来源至少记录：稳定ID、workspaceId、nodeId、标题、相对路径、节点类型、内容类型、扩展名、创建/更新时间、创建者UID/姓名、来源链接、父节点、权限域、盘点状态和批次快照时间。

创建者姓名直接写入`owner`。目录接口未返回时，必须在源workspace内用标题搜索候选、按nodeId精确匹配取得creatorUid，再通过通讯录取得姓名；只有确定性补查仍不可得时才写“待补充”，不得让Codex推测。同名文档不得只按标题选择创建者。

## 2. 格式准入复核

执行下载前复核Raw白名单：

- 允许：钉钉原生文档、DOCX、可检索PDF、含可读取文字的PPTX、XLSX/钉钉表格、CSV、MD、TXT；
- 直接排除：独立图片、音频、视频、压缩包、可执行文件、程序或网页源文件；
- 纯扫描PDF、纯图片PPT以及没有可读取文字的文档退回补充；
- 白名单外文件进入“经Raw入库标准排除清单”，不能静默跳过，也不计入解析失败。

## 3. 稳定ID

```text
{部门前缀}-{SHA256(workspace_id + ":" + node_id)前12位大写十六进制}
```

改名、移动或更新内容不改变稳定ID；删除后重建、复制为新节点会得到新ID。内容哈希不代替稳定ID。

## 4. 获取和解析矩阵

| 类型 | 获取方式 | 处理要求 |
|---|---|---|
| 钉钉在线文字文档 | DWS读取或导出 | 保留标题、链接、正文结构和附件引用 |
| DOCX | 下载并校验Office结构 | 提取正文、表格、页眉页脚和可用批注 |
| 可检索PDF | 下载并校验PDF文件头 | 提取文字、页码和可用表格 |
| 含文字PPTX | 下载并校验Office结构 | 提取每页文字、备注和页面顺序 |
| XLSX/钉钉表格 | 下载或读取表格结构 | 保留工作表、单元格、公式、批注和合并信息 |
| CSV/MD/TXT | 读取并识别编码 | 防止乱码、截断和换行破坏 |

## 5. 下载完整性

原生文件必须校验：

- DWS或HTTP状态；
- 下载字节数大于0；
- 文件头与扩展名相符；
- SHA-256；
- 临时下载地址不写入知识库和公开日志；
- HTML错误页不能被当作附件成功。

## 6. 重试规则

1. 第一次使用标准方式获取和解析；
2. 失败后更换一种经过验证的兼容方式；
3. 第二次仍失败，记录真实阶段、错误、尝试次数、最后时间和建议动作；
4. 不继续无上限重试，不伪造正文，不用模型成功掩盖解析失败。

格式政策排除不是解析失败，不执行两次解析重试。

## 7. 文件大小

不得凭经验或单次失败写死文件大小限制。只有平台明确返回限制，或受控测试证明阈值时，才能写入格式兼容矩阵。超长页面发布时按标题、段落和表格边界分片，禁止在表格、代码块或列表内部截断。

## 8. 成功与失败

解析成功是指取得完整文本并通过完整性校验，或取得允许格式的完整原附件并完成规定解析。

解析失败是指已经通过Raw准入的材料，在两次真实尝试后仍不能取得可验证正文或原附件。失败必须进入清单，不计入成功数。

```text
盘点总数 = Raw准入数 + 经标准排除数 + 待准入处理数
Raw准入数 = 解析成功数 + 二次尝试后失败数
静默遗漏数 = 0
```
