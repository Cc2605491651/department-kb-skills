# 文件格式兼容矩阵

更新日期：2026-07-30。此表记录当前 Skill 的实际处理边界；Raw准入原则以 `raw-admission-standard.md` 为准。

| 来源类型 | 准入 | 主解析方式 | 兼容方式 | 失败/退回条件 |
|---|---|---|---|---|
| 钉钉文档 / `adoc` | 是 | `dws doc read`读取Markdown | `dws doc export`导出DOCX后解析 | 无权限、正文缺失、导出失败 |
| `.docx` | 是 | OOXML读取正文、表格、批注、页眉页脚、脚注尾注 | LibreOffice转纯文本 | 加密、损坏、格式伪装、两种方式均失败 |
| 可检索`.pdf` | 是 | pdfplumber逐页提取文字和表格 | 同解析器兼容重试 | 全文可检索文字不足；纯扫描/纯图片PDF退回文字版 |
| 含文字`.pptx` | 是 | OOXML读取幻灯片、备注和批注 | LibreOffice转PDF后读取可检索文字 | 纯图片PPT、加密、损坏或两种方式均失败 |
| `.xlsx` / 钉钉表格`axls` | 是 | openpyxl读取全部工作表、公式、批注和隐藏表状态 | OOXML直接读取单元格和公式 | 加密、损坏、导出失败或两种方式均失败 |
| `.csv` / `.md` / `.txt` | 是 | 字符集识别后全文读取 | UTF-8替换模式读取并登记告警 | 空文件、疑似二进制、无法形成完整正文 |
| 独立图片 | 否 | 不执行OCR | 无 | 改为带文字说明的Word或钉钉文档后重交 |
| 音频、视频 | 否 | 不转写 | 无 | 提供文字转写稿、纪要或操作说明后重交 |
| 压缩包 | 否 | 不自动解压 | 无 | 人工解压后按成员文件逐项提交 |

## 大小与数量边界

- Raw文件不设置脱离平台的固定大小值；必须低于提交时钉钉/DWS允许的上限，并能完整下载、打开和校验SHA-256。
- 超大文档应按完整章节、工作表或业务对象拆分，保留共同来源链接，禁止按任意字节切割原文件。
- Codex长文按连续内容片段处理，所有片段可逐字还原后再汇总画像。
- 钉钉发布的单次Markdown请求实测不能超过10,000字符；Skill固定以9,000字符为安全片段上限。
- DWS发布并发和单批任务数固定上限30。该限制针对知识页创建、更新和回读，不等同于OSS文件上传压测并发。

## 运行依赖

- 必需命令：`dws`、`codex`。
- 文档运行时：Python及`charset_normalizer`、`openpyxl`、`pdfplumber`。
- 兼容转换可选：LibreOffice `soffice`。缺少时主解析仍可运行，只有主解析失败后的Office兼容重试不可用。

格式、平台限制或解析器版本变化后更新本表，并重新运行 `tests/test_skill.py` 与 `scripts/preflight.py`。
